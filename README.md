# Hive School Piscine Projects 🐝

Welcome to my repository of projects from the **Hive School Piscine**—a rigorous programming bootcamp designed to immerse participants in the fundamentals of coding, collaboration, and problem-solving. Hive is a part of the renowned [42 Network](https://42.fr/en/homepage/), known for its innovative and peer-to-peer learning approach.

## 🚀 About the Piscine

The **Piscine** (French for "swimming pool") is an intensive 4-week program where participants dive into coding challenges, work collaboratively on projects, and develop essential skills for software development. This experience emphasizes self-learning, teamwork, and adaptability, preparing participants for the full Hive curriculum.

## 📂 Repository Structure

Each folder in this repository represents a specific project or challenge from the Piscine.

Additional details and instructions can be found in the PDF files within each project directory.

## 🛠️ Technologies and Tools

Throughout the Piscine, I worked with:
- **C programming language**: For mastering low-level programming concepts.
- **Shell scripting**: For automation and system tasks.
- **Version control with Git**: To collaborate effectively and manage project versions.
- **Peer code reviews**: To enhance learning through collaboration.

## 🌟 Key Skills Developed

- Problem-solving and debugging.
- Writing clean and efficient code.
- Collaborating in a peer-to-peer learning environment.
- Adapting to challenging and unfamiliar concepts quickly.
